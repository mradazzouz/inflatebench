# Example figures (synthetic data)

Rendered from synthetic runs (`tests/prereg_synth.py`), not from real results, to show the
layout of the analysis figures. `combined_*`: `ib analyze --runs ... --out-id combined` over two
models; `*_low_rates_*`: behavioural rates of 1-6% and recall near 1, like the real runs;
`single_*`: a single-run report; `three_models_*`: three models side by side. The report writes
each figure as PNG (300 dpi) and PDF.
