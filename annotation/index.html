Constraint inflation: human labels

How to use

Enter your name, then load the sample JSONL (one summary item per line, made by make_annotation_sample). For each item, read the summary, pick one label, and select the summary text that supports it (the selection fills the quote box). Leave the quote empty when the label rests on absence.

Keys: 1–8 label, →/← next/previous, n next unlabelled. Labels are kept in this browser as you go; use Save labels to write the JSONL file. Everything runs offline.

You see neither the compaction condition nor the model; label from the text alone.
